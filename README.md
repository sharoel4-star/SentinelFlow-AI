# SentinelFlow AI 
SentinelFlow AI is an explainable AI-powered network intrusion detection
system designed to detect malicious network traffic, classify cyberattacks,
and visualize security threats through an interactive SOC dashboard.

## Project Status
Currently under development.

## Planned Features
- Network traffic analysis
- Malicious traffic detection
- Cyberattack classification
- Explainable AI
- Threat severity assessment
- Interactive SOC dashboard
- Security analytics and reporting

## Tech Stack
Python • Machine Learning • Cybersecurity • Explainable AI • Streamlit
